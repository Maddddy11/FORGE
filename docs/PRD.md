# Product Requirements Document — IMAM Lite

## Problem
Maintenance engineers lose time and make risky decisions because critical asset context is scattered.

## Goal
Provide an agentic co-pilot that retrieves institutional memory and recommends explainable actions with human approval gates.

## MVP KPIs
- MTTD reduction >= 40%
- Top-2 relevance >= 85%
- Compliance detection recall >= 90%
- 100% auditability for high-risk recommendations
